# 全文翻译

## 使用方法

1. 为目标 PDF 准备已由 llm-for-zotero 生成或恢复的 MinerU 缓存。全文翻译会验证 PDF 与父条目的身份，以及 `_llm_source.json`、`manifest.json` 和 `full.md`。
2. 在 Paper Translate 中选中准备使用的模型。全文任务支持现有的 Codex Auth 和 API Key 服务商，包括已配置的本机回环接口。
3. 右键 PDF 附件，选择「全文翻译 / 继续」。只有一份 PDF 的文献条目也可以直接右键操作，也可以点击 PDF Reader 工具栏的「文」按钮。
4. 任务完成后，同一条目下会出现「全文翻译 · 中英对照」HTML 附件。打开后可选择双语、只看中文和只看原文。表格、公式、图片与参考文献在各视图中按需保留。
5. 运行时对同一 PDF 再点一次可暂停。再次启动会继续当前源文件和模型对应的断点。更换模型或更新原 Markdown 后会使用该版本独立的进度。

翻译会向所选模型发送论文文本。使用本机模型时，文本会发送到该本机端点。全文任务不会上传 PDF，也不需要重新运行知识准备。正在运行的全文任务使用启动时选中的模型，可以同时使用划词翻译。

## 实现

- 从现有论文上下文流程抽出只读源校验，全文任务直接读取通过校验的 `full.md`。
- Markdown token 分组用于对齐原文和译文。使用稳定段落 ID、字面量保护标记及校验。模型返回的批次结构无效时尝试单段翻译。
- 全文任务独立串行运行。完成的批次按段落记录并原子保存到 Zotero 数据目录下的 `paper-translate-for-zotero-fulltext/`。断点按附件、Markdown、manifest、模型配置和提示版本区分。断点只记录翻译结果和文件名指纹。
- 输出 HTML 禁用脚本和外部图片请求，数学用现有 KaTeX 的安全 MathML。优先内嵌经过路径和文件类型校验的本地光栅图。重复生成会更新同一 PDF 对应的已有全文附件。
- 主项目的划词、认证、Provider 模型选择和知识准备流程保留。功能开发从 `dev` 的 `c16be82` 切出。

## 验证

在隔离的 Zotero 10.0.8 配置中，用合成论文和模拟模型调用运行全文任务。暂停前发出一批请求，继续后完成剩余一批，再次运行复用已保存结果。三次操作产生一个同条目子附件。Zotero 加载了附件，包含 MathML 和内嵌图片。在浏览器中验证了三种阅读模式。真实文献和模型账号可通过上面的操作流程验证。

## 当前范围

- 需要已校验的本地缓存。条目下只有 MinerU ZIP 时，请先用 llm-for-zotero 恢复缓存。插件内 ZIP 导入、MinerU 上传解析和 PDF 文本降级未接入。
- 本地栅格文件缺失、超出限制或路径无法验证时显示占位。没有明确位置的图片集中显示在文末。图注随 Markdown 正文翻译。
- 参考文献和表格内容保留原文。Markdown 表格与常见 MinerU HTML 表格可显示，复杂 HTML 版式可能降级。全文译文持久化为断点数据和 HTML。
- 小模型的 JSON 或标记遵从能力会影响翻译。任务失败时保留已完成进度，修正模型配置或错误后可继续。
